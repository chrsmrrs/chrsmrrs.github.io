# Christopher Morris — complete website redesign

The complete static website contains the redesigned homepage and 17 subpages, with a light beige background, maroon accents, serif headings, readable course schedules, and mobile layouts.

## Preview

Open `index.html` in a browser. Teaching links now open the included local pages, and all supplied PDFs and seminar templates are included. The additional information pages are `positions.html`, `shk.html`, and `thesis.html`.

## Use on GitHub Pages

Unzip the download. Copy the contents of the `chrsmrrs.github.io` folder into your existing `chrsmrrs.github.io` repository, preserving its `.git` folder. If the download has no containing folder, copy its files directly. The website's `index.html` should be at the repository root.

No installation or build is needed. Commit and push the updated files through your usual GitHub workflow when ready to publish.

The archive contains website files only. Git history, editor backup files, and macOS metadata are excluded. The separate review report is not part of the public website package.

## Editing

- `index.html`: homepage content.
- Semester folders: course pages and downloads, using their existing URLs.
- `homepage.css`: shared colors, typography, and homepage layout.
- `subpages.css`: course and information-page layouts.

The main colors are maroon `#701f32` and light beige `#fcfbf9`.

Dates and contact addresses were kept exactly as requested. Three missing teaching pages were restored from the supplied repository history.

## Typography

Headings use EB Garamond Regular, with natural letter spacing and roomier line spacing. The font is included locally in `assets/fonts/eb-garamond/`, covering Latin and Latin Extended characters, including German accents. Its SIL Open Font License and source information are included alongside the font files.

The three main biography paragraphs use the same smaller font size, `1rem` (16 px), on desktop and mobile.
